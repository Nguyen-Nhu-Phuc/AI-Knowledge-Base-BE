# Security Policy

## Passwords
- Minimum 12 characters for production accounts
- Rotate service credentials every 90 days
- Never share API keys in Slack or email

## Remote access
- VPN required for internal admin tools
- MFA enforced for all admin and owner roles

## Incident response
1. Contain the issue
2. Notify `#security-incidents`
3. File a ticket within 1 hour
4. Post a short postmortem within 5 business days
